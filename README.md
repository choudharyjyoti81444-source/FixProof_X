

\# FixProof X

\### Intelligent Web Security Platform



FixProof X is a web-based security configuration checking platform built using Python and Flask.



\## Features



\- User Registration and Login

\- Secure User Sessions

\- Website URL Validation

\- Five Security Header Checks

\- Security Risk Score

\- Risk Level Assessment

\- Scan History

\- Detailed Security Findings

\- PDF Report Generation



\## Security Checks



1\. HTTPS

2\. Content-Security-Policy (CSP)

3\. Frame Protection

4\. HTTP Strict Transport Security (HSTS)

5\. X-Content-Type-Options



\## Technology Stack



\- Frontend: HTML, CSS, JavaScript

\- Backend: Python, Flask

\- Database: SQLite

\- HTTP Requests: Requests

\- PDF Reports: ReportLab



\## Installation



1\. Clone or download the project.

2\. Open the project folder.

3\. Create and activate a virtual environment.

4\. Install dependencies:



```bash

python -m pip install -r requirements.txt

```



\## Run Application



```bash

python app.py

```



Open in browser:



http://127.0.0.1:5000



\## Responsible Use



Only scan public websites that you own or have permission to assess.



FixProof X checks selected security configuration headers. It is not a complete vulnerability scanner or penetration testing tool.
