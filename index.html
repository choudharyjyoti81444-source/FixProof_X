ABOUT THE PROJECT

Making Basic Web Security Checks Easier

FixProof X is a web-based security configuration checker built using Python and Flask. It helps users understand selected HTTP security header findings through a dashboard, indicative score and downloadable report.

Create Your Account

Responsible Use: Scan only public websites you own or have explicit permission to assess. FixProof X performs selected configuration checks; it is not a complete vulnerability scanner or penetration test.
